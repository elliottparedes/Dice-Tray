# Dice Tray

A dice roller you can open in a browser when you sit down to play Dungeons & Dragons.

Tap the dice you want. They wait in the corner of the tray until you hit Roll, then they get thrown once, with physics. The total shows up big at the bottom. Each die has its own color, and the sound is a low knock on wood.

Throw a single d20 and land on 20, and you get fireworks and a trumpet. A natural 1 gets a sad trombone. Anything else just shows the number.

The dice you picked stay in this browser. Rolls are not sent anywhere.

## Run it

```bash
npm install
npm run dev
```

Open the address Vite prints.
